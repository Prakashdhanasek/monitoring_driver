Deep-Dive: Incident Logic Architecture

Complete technical breakdown of every single driver monitoring event.

GLOBAL GATING RULES (Applies to all incidents)

  • Speed Barrier: ALL incident triggers (Phone, Distraction, Drowsiness, Seatbelt, Smoking, Driver Changed) are hard-gated behind a > 10 km/h minimum speed check. If the vehicle is parked, incidents are processed but NOT alerted or sent to the API.
  • API Cooldowns: ALL repeats are governed by the server's cooldown map. E.g., if Phone Usage has a 180s interval in the API, the app will strictly wait 3 minutes before generating another phone alert, preventing spam.

Phone Usage

Model A YOLO 3-Second Timer
  • Implementation: Driven by ObjectDetectorEngine processing Model A (custom_yolo.tflite).
  • Logic: Triggers ONLY if YOLO predicts a phone bounding box extending past 55% confidence continuously for 3 seconds.
  • Refinements: The legacy jitter/blur logic was removed. It now uses a strict timer with a 1.5s grace buffer (if a hand drops and immediately lifts, the timer resumes instead of resetting).

Smoking

Model A YOLO
  • Implementation: Processed alongside Phone Usage on Model A.
  • Logic: Detects a smoking mechanism/gesture with YOLO confidence > 45%.
  • Refinements: Relies on sustained multi-frame confirmation to prevent false ID from white pens or similar objects.

Seatbelt Unbuckled

Model A YOLO Absence Detection
  • Implementation: Object absence mapping via Model A framework.
  • Logic: A cyclic timer activates in the main event stream. If the YOLO model fails to return a "seatbelt" bounding box, the cyclic audio starts playing.
  • Refinements: Only activates >10 km/h. Instantly shuts off the moment the unbuckled driver stops the vehicle or successfully puts the seatbelt back on.

Distraction

ML Kit Euler Yaw Context-Aware Math
  • Implementation: Dynamically mapped in MonitoringEngine via facial landmark rotation (Euler Angle Y).
  • Logic (Highway / > 40 km/h): Yaw threshold is 25 Degrees. Driver must look away from the road continuously for 3.5 seconds.
  • Logic (City / < 40 km/h): Yaw threshold relaxes to 35 Degrees. Driver must look away continuously for 6 seconds to allow for heavy mirror-checking or side-street checking at intersections.

Mild Drowsiness

PERCLOS / EAR MAR Strike System
  • Implementation: Tracks Eye Aspect Ratio (EAR) and Mouth Aspect Ratio (MAR).
  • Logic (Micro-sleep): Logs a strike instantly if the EAR drops deeply for < 800ms, and happens 3 times within a 30-second window.
  • Logic (Yawning): Logs a strike if MAR stays > 60% (mouth wide open) for 1.5 seconds.
  • Alerts: Plays Strikes 1-4 audio. Logs 'Drowsiness' incident.

Severe Sleepiness (Wake Up)

Continuous Timer Euler Pitch
  • Implementation: Bypasses strikes completely for immediate alarm override.
  • Logic (Actual Sleep): Eyes closed continuously for 7 seconds.
  • Logic (Head Drop): Pitch angle drops drastically (< -12 Degrees or> 15 Degrees) continuously for 7 seconds.
  • Alerts: Triggers massive red Screen UI, loud blaring TTS (WAKE UP), and uploads Critical Sleepiness Incident.

Driver Changed

FaceNet Embedding Space 12s Buffer
  • Implementation: Uses Mobile FaceNet inference to extract a 192-dimensional vector embedding.
  • Logic: Triggers if the current active face embedding distance fails to match the original driver embedding.
  • Occlusion Fix: Upgraded to tolerate exactly 12 continuous seconds of occlusion (covering face, wearing heavy sunglasses, wiping sweat) before firing the unauthorized alarm.

Multiple Persons Detected

Facial Multi-tracking
  • Implementation: Hooks into ML Kit's multi-face native bounding box array.
  • Logic: Triggers the moment the camera captures > 1 distinct facial bounding boxes within the designated driver scanning region.

Camera Blocked (No Face)

Null Detection
  • Implementation: Triggers when the master ML Kit frame array returns null natively.
  • Logic: Given a 5-second grace countdown (to account for shadows or hand-blocks). After 5 seconds, flags monitoring state to warn fleet managers that the camera is completely blocked or broken.

Overspeeding & Geofencing (Telemetry)

GPS Stream Overtaking Buffer Polygon Ray-Casting
  • Overspeeding 10-Second Buffer Engine:
    1. Speed > Threshold: Starts a silent 10-second timer (No report is triggered immediately).
    2. Speed drops within 10s: Timer cancels natively without any incident logged (Allows for aggressive but brief overtaking).
    3. Speed stays high for 10+ seconds: Timer completes and fires an Overspeeding incident payload containing the Peak Speed recorded during that window.
  • Geofence Logic: Uses complex mathematical Ray-Casting for Polygons and Haversine distances for Circles. Triggers RESTRICTED AREA or OUT OF BOUNDARY instantly upon GPS location breach.
NOTICE: All of the metrics, timers, and changes detailed in this architecture document are currently in active testing for final accuracy calibration.
